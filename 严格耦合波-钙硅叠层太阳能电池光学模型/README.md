## 🚀 运行方式

### 1. 启动仿真系统
直接运行 `main.py` 即可进入交互式菜单：
```bash
python main.py
```

### 2. 功能选项
- **收敛性测试**：自动寻找最佳仿真精度。
- **单点验证**：快速测试一个标准结构。
- **并行扫描**：全自动化、多进程搜索最优参数。
- **性能对比**：一键对比织构电池相对于平面的增益。
